# User Stories

This document captures agile user stories mapping to the Functional Requirements.

## Core User Stories (Unverified)

- **US-001**: As a public user, I want to report a distressed animal using my phone's camera and location, so that rescue organizations can be alerted.  
  *Status*: **PROPOSED / DISCUSSION**
- **US-002**: As an AI Agent, I want to pre-process incoming animal photos to identify severity and species, so that human dispatchers can prioritize critical cases.  
  *Status*: **PROPOSED / DISCUSSION**
- **US-003**: As a dispatcher/admin, I want to verify AI-generated triage assessments, so that I can safely assign a volunteer.  
  *Status*: **PROPOSED / DISCUSSION**
- **US-004**: As a volunteer, I want to receive proximity-based push notifications for new rescue cases, so that I can respond quickly.  
  *Status*: **UNKNOWN — REQUIRES DECISION**
- **US-005**: As a veterinarian, I want to access an animal's rescue profile to log medical treatment, so that the NGO can track recovery.  
  *Status*: **UNKNOWN — REQUIRES DECISION**
- **US-006**: As an NGO admin, I want to transition a recovered animal to an 'Available for Adoption' state, so that the public can apply to adopt.  
  *Status*: **UNKNOWN — REQUIRES DECISION**
- **US-007**: As a donor, I want to contribute funds to a specific rescue campaign, so that I can support cases I care about.  
  *Status*: **UNKNOWN — REQUIRES DECISION**
